# 器件结构参数库

这里保存可复用的器件参数。后续结构继续以独立 JSON 文件加入本目录，避免覆盖已有结构。

| 参数文件 | 电学层结构（左 → 右） | 光照设置 |
| --- | --- | --- |
| [器件air入射-3.0渐变1.53参数.json](器件air入射-3.0渐变1.53参数.json) | NiOx 20 nm / 3.0→1.53 eV 渐变钙钛矿 50 nm / 1.53 eV 钙钛矿 750 nm / C60 40 nm | AM1.5G，Air 左侧入射，前侧 Air 200 nm，背电极 Ag 100 nm，300–800 nm |

在「器件性能模拟 → 打开参数」中选择 JSON。文件包括材料、电极、复合、光学、扫描及 EQE 设置，两层钙钛矿均开启光生载流子。保留提交时的原始参数，厚度优化结果不会反写进此文件。

当前结构的 NiOx 光学数据按原文件采用 PTAA 示例 n,k；渐变层吸收边参考带隙为 3.0 eV，均匀层为 1.53 eV。此处用于复现给定模型，不代表已校准的实验器件。

新增结构时请使用明确的文件名，在上表登记层顺序、入射方向和适用页面；自定义光谱与 n,k 应内嵌在参数文件中。
