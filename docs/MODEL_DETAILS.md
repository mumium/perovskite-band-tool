# 1.3 模型与数值约定

## 界面 SRH

沿用 SimSS 5.36 原生模型，未修改物理求解器。每个原材料层的 `interface` 指定与右侧材料的界面：Nt/cm⁻²、Cn/Cp/cm³·s⁻¹、Et/真空以下正深度 eV、trap_type (-1 受主、0 中性、1 施主)。单位分别乘 1e4、1e-6 转为 SI；默认 Nt=0。

自动能级取两侧接触端材料共同禁带的中点：low=max(χ左端接界, χ右端接界)，high=min(χ+Eg 两侧端点)，Et=(low+high)/2。开启陷阱时要求 low<Et<high；这不是自洽静电势作用后的局部带边。手动 Et 采用相同真空参考。

只在相邻原材料的真实界面启用；渐变数值子层之间 Nt=0，体迁移率匹配保留。右侧入射时反转层序、梯度端点、电学接触，并将界面参数随同一个物理界面移动。最后一层没有右界面。带电陷阱参与原生泊松耦合，高浓度与强梯度时不保证收敛，失败不采用部分曲线。

## 基础吸收边联动

设原始数据为 n₀(λ)、k₀(λ)，参考带隙 Eg₀，局部电学带隙 Eg。光子能量 E=hc/λ，源数据最高能量 Emax=hc/λmin。对 E≥Eg 定义：

```
Eref = Eg₀ + (E−Eg)·(Emax−Eg₀)/(Emax−Eg)
α₀(Eref) = 4π·k₀(hc/Eref)/(hc/Eref)
knew(λ) = α₀(Eref)·λ/(4π)
nnew(λ) = n₀(λ)
```

波长在 α 和 k 的换算中使用 m。E<Eg 时 knew=0。此能量轴重映射使局部带隙对应参考吸收边，源数据短波端固定；不是整条谱的刚性平移。参考 Eg 必须位于源光学数据覆盖能量内，当前 Eg 小于最高覆盖能量；验证后仅用线性插值，端点裁剪只吸收浮点舍入误差，不外推数据。

新示例 MAPI 的参考 Eg=1.55 eV 为演示约定，不代表当前样品的测量带隙。Eg=Eg₀ 时，带隙以上使用原始吸收，带隙以下截断吸收尾。渐变使用各数值子层的 Eg；只有电学掺杂/亲和能变化而 Eg 不变时，此光学模型不变。

此基础近似保持 n 不变，没有求解由 k 变化引起的色散一致性，不描述真实组分依赖、Urbach 尾、激子、温度/掺杂相关吸收等。研究实测谱或吸收尾时应选固定 n,k；手动 G 模式不使用联动。结果保存原始和有效 n,k、参考/局部 Eg 及数据指纹。

## 损失分析

读取原生 JV.dat 中 JphotoL、JbulkL、JdirL、JintLiLj，A/m² 除以 10 得到 mA/cm²。渐变子层聚合回原材料，虚拟界面不加入真实界面列表。真实界面复合使用原生电子/空穴界面复合的平均等效电流，带符号保留净生成/净复合。

按端电压对原生积分分量线性插值；工作点为短路 V=0、已确认的 Vmp 或 Voc，不外推。端电流以发电为正。漏电为原生 JShunt/10；电流预算定义：

```
边界/离散残差 = ΣJphoto − J输出 − ΣJbulk − ΣJdir − ΣJinterface − JShunt
串联电阻耗散 (mW/cm²) = J输出(mA/cm²)² · Rs(Ω·cm²) / 1000
```

残差包含接触/边界处理以及不同积分区间的数值差异，不能全部解释为接触复合。光生电流参考 q∫Gdx 与逐层 Jphoto 的总和也可能因离散积分区间不同而有差异。此处不提供完整光学反射/透射/寄生吸收的分解，不提供效率损失百分比分解。图表按可用高度展示最大若干项及其余合计，最多八行，CSV/JSON 保留全部。

## 短路微分 EQE

参考上游 [pySIMsalabim EQE 工作流](https://github.com/kostergroup/pySIMsalabim/blob/main/pySIMsalabim/experiments/EQE.py)，实现采用本项目已有 NumPy 与 SimSS，无新增运行依赖。

1. 用当前完整光谱归一化到 Pin，在光学计算波段内建立 1 nm 网格，并乘以背景比例（默认 1）。
2. 在 Vext=0 求背景电流 J₀。对每个待测波长，独立重置背景谱，仅在该 1 nm 波长格增加 ΔΦ·hc/λ 的入射功率。
3. 每次重新运行原生 TMM 与稳态电学，得到 Jλ，计算 EQE=(Jλ−J₀)/(q·ΔΦ)。默认 ΔΦ=1e14 cm⁻²·s⁻¹，波长采样间隔 10 nm，最多 251 点。

SimSS TMM 以 1 nm 矩形格求和且包含端点，探测光分母与此单格带宽一致。写出 SI 波长时使用固定十进制精度，匹配原生网格，避免浮点舍入使原生线性插值错过窄峰。取探测前后 G(x) 差值并积分，得到图中的光生吸收参考。

返回带符号 EQE，不取绝对值、不截到 0–1。报告 `(errJλ+errJ₀)/(q·ΔΦ)` 的数值误差估计（原生 RMS 电流不均匀度换算），它不是统计置信区间，也不能替代网格/探测通量收敛检查。

光谱加权电流为 q∫EQE(λ)·Φ(λ)dλ，在已有波段内插值和积分。因 EQE 是给定背景下的微分响应，强度依赖或非线性收集时不保证等于同一光源下的 Jsc。波段外不补全 EQE。应比较更细波长采样、更小探测通量及更密空间网格；过小通量可能被数值噪声淹没。

EQE/J–V 结果各自保存完整输入快照。失败或取消不覆盖最近成功结果；EQE 图与导出使用 EQE 快照。Jsc/Voc/FF/PCE 卡片保持最近 J–V，在 EQE/损失视图暂时收起，切回 J–V 恢复。
